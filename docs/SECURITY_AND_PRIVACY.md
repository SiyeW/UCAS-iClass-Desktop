# 安全与隐私

## 当前行为

- 账号、密码和会话只保存在进程内存中。
- 关闭应用或点击退出后，当前内存状态被清除。
- 当前版本不写入凭据文件、Cookie 文件或本地数据库。
- 登录、课程查询和手动签到需要与学校服务通信。

## 使用建议

- 不要在公共或他人管理的 Windows 账户中输入学校密码。
- 不要在 Issue、日志、截图或 Pull Request 中提交账号、密码、会话标识、完整二维码 URL 或课程 UUID。
- 如需排查网络问题，请先删除或掩码姓名、学号、课程标识和 Cookie。

## 尚未实现的功能

本项目目前没有凭据持久化、托盘后台运行、自动签到、开机启动或计划任务。后续若引入这些功能，必须同时说明数据保存位置、清除方式、触发条件、失败处理和用户关闭机制。
