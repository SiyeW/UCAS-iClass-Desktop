# 安全与隐私

## 当前行为

- 默认情况下，账号、密码和会话只保存在进程内存中。
- 关闭应用或点击退出后，当前内存中的会话和密码会被清除。
- 默认不写入凭据文件、Cookie 文件或本地数据库。
- 登录、课程查询和手动签到需要与学校服务通信。

## 可选的本机登录信息保存

- 只有用户主动勾选“在此 Windows 账户中记住登录”并登录成功后，程序才会保存账号和密码。
- 保存内容经 Windows Data Protection API（DPAPI）加密，通常只能由同一台电脑上的同一 Windows 账户解密。
- 加密文件路径为 `%LOCALAPPDATA%\UCASiClassDesktop\credentials.dpapi`。文件不包含会话 Cookie，也不会自动发起登录请求；程序只在启动时预填登录框，仍需由用户点击登录。
- 可在登录页或已登录界面选择“清除本机保存的登录信息”。取消勾选也会清除已保存的登录信息。
- DPAPI 不是替代 Windows 账户安全、磁盘加密或恶意软件防护的方案；请勿在不可信或多人共用的 Windows 账户中启用此选项。

## 使用建议

- 不要在公共或他人管理的 Windows 账户中输入学校密码。
- 不要在 Issue、日志、截图或 Pull Request 中提交账号、密码、会话标识、完整二维码 URL 或课程 UUID。
- 如需排查网络问题，请先删除或掩码姓名、学号、课程标识和 Cookie。

## 尚未实现的功能

本项目目前没有托盘后台运行、自动签到、开机启动或计划任务。后续若引入这些功能，必须同时说明数据保存位置、清除方式、触发条件、失败处理和用户关闭机制。
